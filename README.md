# Atlas Assets

Cross-border structure-modeling and professional-coordination concept for founders, companies, intellectual property and digital-asset operations.

Public website: https://atlasassets.josephjilovec.com/

## Public experience

- `/` — proposition, scenario categories and service boundaries.
- `/jurisdictions` — jurisdiction/dependency presentation.
- `/structures` — structure-modeling overview.
- `/simulation` — illustrative scenario-review interface.

The experience organizes facts, assumptions and questions for qualified professional review. Scenario displays do not establish legal, tax, securities, fiduciary or banking conclusions. Atlas does not take custody of client assets or execute transfers, and the public source does not establish a deployed private client workspace.

## Development

Next.js App Router and TypeScript.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Use the existing Vercel project and repository-root settings. Optional service-routing configuration belongs server-side; consult `.env.example` for variable names. Keep credentials out of source control and client bundles. Review endpoints should remain unavailable for production submissions until an approved secure routing service is configured and tested.

Detailed operating plans, commercial assumptions and future system design are maintained in restricted internal records. Earlier documentation may remain in public Git history.
